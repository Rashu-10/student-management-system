# Student Management System

## Description
A web-based application using Python, Flask, and SQLite to manage student records efficiently. Perform CRUD operations—add, view, edit, and delete student details. Stores information like name, age, course, and email, providing a simple, user-friendly interface for educational institutions.

## Features
- Add, view, edit, and delete student records
- SQLite database integration
- Easy-to-use web interface
- Reduces manual work in managing student information

## Tech Stack
- Backend: Python, Flask
- Database: SQLite
- Frontend: HTML, CSS, JavaScript
